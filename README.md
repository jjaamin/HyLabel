# HyLabel

세그멘테이션 마스크 라벨링 도구. 폴리곤 · 브러시 · AI 매직완드로 마스크를 그리고 **LabelMe JSON** 형식으로 저장합니다.

**주요 기능**

- 폴리곤 / 브러시 / Lasso 기반 세그멘테이션 라벨링
- SAM 계열(EdgeSAM · SAM2 · SAM2.1) AI 매직완드로 클릭 한두 번에 마스크 자동 생성
- Edge refinement — 모델이 물체 안쪽에 그린 컨투어를 실제 경계로 밀어냄
- 클래스 · 레이블 · 이미지 관리 패널 (클래스 순서로 겹침 우선순위 조절, 눈 아이콘으로 표시/숨김)
- 학습용 image / label PNG로 내보내기 (클래스 값이 곧 픽셀 값인 8bit 마스크)
- 마스크 오버레이 렌더링, 감마 커브 보정 등 보기 편의 기능

> DMI 영상응용계측기술팀 · 구자민 TL

## 설치 (다른 PC에 처음 설치하는 경우)

### 1. Python 설치

**Python 3.8 이상** 필요 (개발·테스트는 3.13 기준). [python.org](https://www.python.org/downloads/) 에서 설치 시 **"Add python.exe to PATH"** 체크.

설치 확인:
```bash
python --version
```

> 소스는 3.8 문법으로 유지합니다 — 사내 PC처럼 Python을 올리기 어려운 환경이 있어서입니다.
> 다만 3.8은 이미 지원이 끝난 버전이라 `pip`이 그 버전을 지원하는 **마지막 패키지**를 골라
> 설치합니다. 선택할 수 있다면 3.10 이상을 권장합니다.
>
> **`requirements.txt`의 하한을 올릴 때 주의하세요.** 3.8에 설치 가능한 마지막 버전이
> `numpy 1.24.4`, `scipy 1.10.1`이라 현재 하한(`numpy>=1.24.0`, `scipy>=1.10.0`)이
> 여유 없이 딱 맞물려 있습니다. 여기서 한 단계라도 올리면 3.8에서는 설치 자체가 실패합니다.
> (나머지는 여유 있음: PyQt6 6.7.1 · opencv-python 5.0 · onnxruntime 1.20.1 · huggingface_hub 0.36.2)

### 2. 소스 받기

Git이 설치되어 있으면:
```bash
git clone https://github.com/jjaamin/HyLabel.git
cd HyLabel
```
Git이 없으면 GitHub에서 "Code → Download ZIP"으로 받아 압축 해제.

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

`requirements.txt`에 포함된 것: PyQt6, numpy, opencv-python, scipy, huggingface_hub, onnxruntime.

> `pip`이 없거나 오류가 나면 `python -m pip install --upgrade pip` 먼저 실행.

### 4. AI 매직완드 모델 다운로드 (선택)

AI 매직완드는 클릭 한두 번으로 마스크를 자동 생성하는 기능입니다. 이 기능을 쓰지 않을 거면 이 단계를 건너뛰어도 앱은 정상 실행됩니다.

사이드바 **AI Model** 드롭다운에서 모델을 고를 수 있습니다. 현재 선택지는 **EdgeSAM**, **SAM2 (Hiera-Large)**, **SAM2.1 (Hiera-Large)** 세 가지이며, 사용할 모델의 가중치를 미리 받아둬야 합니다.

```bash
python download_weights.py                      # EdgeSAM (기본값, ~40MB)
python download_weights.py --model sam2_large    # SAM2 Hiera-Large (~890MB)
python download_weights.py --model sam2_1_large  # SAM2.1 Hiera-Large (~870MB)
```

- **EdgeSAM**: 가볍고 빠름. 간단한 대상에 적합. **GPU 없는 PC에서는 사실상 이 모델을 써야 합니다** (아래 CPU 항목 참고).
- **SAM2 (Hiera-Large)**: 정확도가 높아 배경 오검출이 적음. 대신 무겁고 느림.
- **SAM2.1 (Hiera-Large)**: SAM2와 아키텍처가 같은 개선판. 자체 TEM 이미지 비교에서는 SAM2와 정확도·속도가 사실상 동등했으므로, 둘 중 아무거나 쓰셔도 됩니다.

> 이전에 실험용으로 지원했던 SAM2 Hiera-Tiny / Base+는 Large 대비 성능이 떨어져 드롭다운에서 숨겼습니다. 필요하면 `--model sam2` 또는 `--model sam2_base_plus`로 가중치를 받고 `labeler/sam_worker.py`의 `MODEL_INFO`에서 `"hidden": True`를 지우면 다시 노출됩니다.

#### CPU 전용 PC (GPU 없는 회사 PC 등)

**추가 설치는 필요 없습니다.** `requirements.txt`의 `onnxruntime`이 CPU용 패키지라 3번 단계만으로 매직완드가 동작합니다. GPU가 없으면 앱이 자동으로 CPU로 실행됩니다 (모델 로드 후 상태바에 `(CPU)` 표시).

다만 **모델 선택이 중요합니다.** 553×555 TEM 이미지 기준 실측:

| 모델 | 이미지 인코딩 | 클릭당 예측 |
|---|---|---|
| EdgeSAM | **0.3초** | 39ms |
| SAM2 / SAM2.1 (Hiera-Large) | **5.9초** | 33ms |

인코딩은 이미지당 한 번만 수행되고 이후 클릭은 캐시를 씁니다. 하지만 SAM2 계열은 **이미지를 바꿀 때마다 약 6초간 창이 대기 커서로 멈춥니다** (추론이 메인 스레드에서 실행됨). 이미지를 자주 넘기며 작업한다면 CPU PC에서는 EdgeSAM을 권합니다.

GPU가 있는 PC에서는 같은 인코딩이 0.24초라 SAM2 계열도 쾌적합니다.

#### GPU 가속 사용 시 (NVIDIA GPU + CUDA 12.x)

```bash
pip install onnxruntime-gpu==1.20.1
pip install torch --index-url https://download.pytorch.org/whl/cu121
```
onnxruntime-gpu는 cuDNN 9가 필요한데, 위처럼 PyTorch(CUDA 빌드)를 같이 설치해두면 앱이 PyTorch에 번들된 `cudnn64_9.dll`을 자동으로 찾아 쓰므로 cuDNN을 별도로 설치할 필요가 없습니다. PyTorch를 설치하지 않으면 cuDNN을 직접 설치해야 GPU 가속이 동작합니다.

> `onnxruntime`(CPU)과 `onnxruntime-gpu`를 함께 설치해도 무방합니다. GPU 빌드가 우선 사용되며, CUDA를 못 찾으면 자동으로 CPU로 내려갑니다.

> **`onnxruntime_providers_cuda.dll` 로드 실패 빨간 에러가 뜬다면** — `onnxruntime-gpu`는 설치됐는데 CUDA/cuDNN을 못 찾은 경우입니다. 앱은 그대로 CPU로 동작하므로 치명적이지 않습니다. GPU 가속이 필요하면 위의 PyTorch(CUDA 빌드)를 설치하고, 필요 없으면 `pip uninstall onnxruntime-gpu`로 에러를 없앨 수 있습니다.

### 5. 설치 확인

```bash
python run_hylabel.py
```
창이 뜨면 설치 완료.

### 클래스 관리

1. 우측 **Classes** 패널에서 `+ Add` 클릭
2. 클래스 이름 입력
3. 클릭으로 활성 클래스 선택 (볼드체로 표시)
4. 불필요한 클래스는 선택 후 `− Remove` (어노테이션이 없을 때만 삭제 가능)

#### 클래스 우선순위 (순서 바꾸기)

Classes 목록의 **순서가 곧 우선순위**입니다. 목록에서 **아래쪽 클래스가 위쪽을 덮습니다.**

- **드래그 앤 드롭**: 목록 안에서 항목을 끌어 원하는 자리에 놓기
- **`▲` / `▼` 버튼** 또는 **`Ctrl+↑` / `Ctrl+↓`**: 선택한 클래스를 한 칸씩 이동

순서가 영향을 주는 곳은 세 군데입니다.

| | 효과 |
|---|---|
| **캔버스** | 겹친 영역에서 나중 클래스가 **65%**, 앞 클래스가 35% 비율로 섞입니다. 완전히 덮지 않아 밑에 깔린 클래스도 계속 보입니다 |
| **저장 (JSON)** | 아래쪽 클래스의 shape가 파일에 나중에 기록됩니다. shape를 순서대로 마스크에 그리는 도구(AnyLabeling, 학습용 마스크 변환 등)에서 아래쪽이 위쪽을 덮어씁니다 |
| **Labels 패널** | 나열 순서가 같이 바뀝니다 |

순서를 바꾸면 **열려 있는 모든 이미지**의 어노테이션이 새 순서로 다시 정렬됩니다. 클래스
색상은 순서가 아니라 클래스에 묶여 있어 그대로입니다.

> 섞이는 비율은 `mask_manager.py`의 `MaskManager.OVERLAP_MIX`(기본 `0.65`)입니다. `0.5`면
> 예전처럼 단순 평균이 되고, `1.0`이면 나중 클래스가 앞 클래스를 완전히 가립니다.

#### 클래스 숨기기 (눈 아이콘)

각 클래스 이름 왼쪽의 **눈 아이콘을 클릭**하면 그 클래스가 캔버스에서 사라집니다. 다시
누르면 돌아옵니다. 포토샵의 레이어 표시/숨김과 같습니다.

- 눈 아이콘 영역만 토글로 동작합니다 — 이름이나 색상 칩을 클릭하면 평소처럼 활성 클래스가 바뀝니다
- 숨긴 클래스는 **이름이 회색**으로, 눈 아이콘에 **사선**이 그어집니다
- 숨긴 클래스는 **캔버스에서 클릭해 선택할 수 없습니다** (안 보이는 레이블이 잡히지 않도록). Labels 패널에서는 그대로 보이고 선택할 수 있습니다
- 숨긴 클래스의 컨투어 점도 함께 숨겨집니다
- **지금 그리는 중인 마스크는 클래스를 숨겨도 계속 보입니다** — 숨긴 클래스로 작업하다 붓이 안 보이는 일을 막기 위한 것입니다
- 숨김 상태는 **저장되지 않습니다**. JSON에 기록되지 않고, 폴더를 다시 열면 전부 보임 상태로 시작합니다

#### 항목 개수

Classes · Labels · Images 세 패널 모두 **오른쪽 위에 현재 항목 개수**가 표시됩니다.

### Lasso 도구 (`L`)

폴리곤처럼 꼭짓점을 하나하나 클릭할 필요 없이, **외곽선을 마우스로 쭉 드래그하면
내부가 자동으로 채워지는** 도구입니다.

- **좌클릭 + 드래그**: 외곽선 그리기
- **마우스를 떼면** 그린 영역이 채워짐 → **Enter**: 마스크 확정
- **우클릭** 또는 **Esc**: 그리던 외곽선 취소

사이드바의 **Straight** 슬라이더(0\~20px, `[` / `]` 또는 **Shift + 마우스 휠**로도 조절)로
손떨림을 억제할 수 있습니다. 이 값만큼 떨어지기 전에는 새 꼭짓점을 찍지 않으므로, 그
구간은 반드시 직선이 됩니다. 0이면 브러시처럼 커서를 그대로 따라가고, 값을 올릴수록
굴곡이 완만해집니다. 단위는 화면이 아니라 원본 이미지 픽셀이라, 줌 배율과 상관없이
항상 같은 모양으로 그려집니다.

시작점에는 선과 같은 색의 작은 원이 표시됩니다. 드래그 중 커서가 이 시작점에서
**화면상 5px 이내**로 들어오면 자석처럼 달라붙어, 끝점이 시작점과 정확히 맞물려
닫힙니다(원이 채워진 모양으로 바뀌어 알려줍니다). 시작점 근처를 일부러 지나가고
싶다면 **Alt**를 누른 채로 움직이면 되고, Alt를 떼면 다시 자석 기능이 동작합니다.

### Brush 도구 (`B`)

- **좌클릭 + 드래그**: 마스크 칠하기
- **우클릭 + 드래그**: 마스크 지우기
- `[` / `]` 또는 **Shift + 마우스 휠**: 브러시 크기 조절
- **Enter**: 마스크 확정
- **Esc**: 취소

커서는 매끈한 원이 아니라 **실제로 칠해질 픽셀의 외곽선**을 그대로 보여주고, 내부는
현재 클래스 색으로 반투명하게 채워집니다 — 클릭하기 전에 어디가 무슨 색으로 칠해질지
바로 알 수 있습니다. 커서 위치도 클릭 시 사용될 정수 픽셀로 스냅되므로, 화면에 보이는
계단 모양이 클릭했을 때 마스크에 찍히는 모양과 정확히 일치합니다.

브러시는 원이지만 **끝이 뾰족하지 않게 다듬은 원**입니다. 채워진 원은 어떤 크기에서든
위·아래·왼쪽·오른쪽 끝이 딱 1픽셀로 끝나는데, 그 상태로 경계선을 따라 칠하면 윤곽에
1픽셀짜리 돌기가 남습니다. 그 네 곳을 크기에 따라 다르게 다듬습니다.

| 크기 | 처리 | 폭 |
|---|---|---|
| 1 | 그대로 (5픽셀 십자) | 3px |
| 2 \~ 9 | 뾰족한 끝을 3픽셀로 **넓힘** | `2n+1` |
| 10 이상 | 끝부분을 아예 **잘라냄** | `2n-1` |

작은 크기는 줄 수가 몇 개 안 되어 잘라내면 원이 뭉개져 사각형이 되므로 넓히고, 큰 크기는
넓혀 놓으면 3픽셀 돌기가 테두리에 튀어나온 것처럼 보이므로 잘라냅니다. 큰 크기에서 사방
1픽셀씩 줄어드는 것은 눈에 띄지 않습니다.

크기 1은 다른 브러시가 닿지 못하는 좁은 곳을 메우려고 쓰는 것이라 뾰족한 끝을 그대로 뒀습니다.

이미 칠해진 영역의 투명도는 다른 레이블과 완전히 동일하게 `V`를 따라갑니다 — 브러시로
편집 중이라고 해서 더 진하거나 흐리게 보이지 않습니다.

#### 레이블 편집 중 브러시 사용

Labels 패널에서 레이블을 선택한 뒤 `B`를 눌러 기존 마스크를 직접 수정할 수 있습니다.
브러시 모드에서는 컨트롤포인트 점이 흐리게 표시되어 경계선을 가리지 않습니다.

붓이 닿은 구간만 새로 그려지고 **나머지 윤곽은 원본 좌표가 그대로 보존**되므로, 다른 툴에서
만든 JSON을 열어 일부만 손봐도 나머지 정점이 계단 윤곽으로 바뀌지 않습니다. 자세한 내용은
[레이블 편집](#레이블-편집)의 좌표 보존 항목을 참고하세요.

### AI 매직완드 도구 (`M`)

EdgeSAM · SAM2 · SAM2.1 모델로 마스크를 자동 생성합니다. 사이드바 **AI Model** 드롭다운에서 모델을 전환할 수 있으며, 선택은 다음 실행에도 유지됩니다.

- **좌클릭**: 포함할 영역 지정 (초록 점)
- **우클릭**: 제외할 영역 지정 (빨간 점)
- `[` / `]`: 마스크 후보 선택 (1/3 ~ 3/3, 작은 것 → 큰 것)
- `R`: Edge refinement ON/OFF
- **Enter**: 마스크 확정
- **Esc**: 초기화

> 선택한 모델의 가중치와 `onnxruntime` 패키지가 필요합니다. 가중치 다운로드는 [설치 4단계](#4-ai-매직완드-모델-다운로드-선택)를 참고하세요.

#### Edge refinement (`R`)

모델이 만든 컨투어는 대체로 물체의 **안쪽 가장자리**에 붙습니다. Edge refinement를 켜면
컨투어의 각 점에서 **바깥쪽 수직 방향**으로 search range만큼 훑어서 더 확실한 edge를 찾아
그쪽으로 옮깁니다.

- 사이드바 **Edge refinement** 체크박스 또는 매직완드 모드에서 **`R`** 키
- **Search 슬라이더**: 1 ~ 40 px (기본 **20 px**)
- 기본값은 **꺼짐**. 매 실행마다 꺼진 상태로 시작하고, search range 값만 기억합니다
- 켜고 끄거나 range를 바꿔도 **AI 재예측은 하지 않습니다** — 모델 출력은 그대로 두고 다시 정제만 합니다

**바깥 방향**은 앞뒤 컨투어 좌표로 접선을 구한 뒤 그 수직 방향으로 정의하고, 마스크 바깥으로
나가는 쪽을 컨투어 전체 다수결로 고릅니다. 구멍이 있는 마스크에서도 구멍은 유지됩니다.

**애매하면 옮기지 않습니다.** 어떤 점이 새 위치를 확정하려면 네 가지를 모두 통과해야 합니다.

| 검사 | 내용 |
|---|---|
| 탐색 범위 안에서 정점 도달 | 범위 끝까지 계속 세지고 있으면 = edge가 range 밖 → 거절 |
| 현재 위치보다 1.5배 이상 강함 | 이미 edge 위에 있는 점이 노이즈로 흘러가지 않도록 |
| 해당 컨투어의 강한 edge 수준 대비 35% 이상 | 기준을 **그 컨투어 자체**에서 뽑으므로 저대비 물체는 기준도 낮아짐 |
| 자기 탐색선의 노이즈 대비 4σ 이상 | 질감 없는 영역이 노이즈를 edge로 착각하지 않도록 |

통과하지 못한 점은 **결정을 보류**하고, 주변에서 edge를 찾은 점들로부터 보간해 채웁니다.
추가로:

- 이웃과 동의하지 않는 **고립된 점은 버립니다** (5점 창에서 3점 미만이면 노이즈로 간주)
- 컨투어의 **25% 미만**만 edge를 찾았다면 전체를 보간하지 않고, 찾은 점 주변 5점까지만
  반영하고 나머지는 원래 자리에 둡니다 — 근거가 얇을 때 윤곽 전체를 끌고 가지 않기 위한 것
- 보간 후 원형 median(5) + 평균(5) 필터로 튀는 점과 계단을 정리합니다

상태바에 `1176/1176 points found an edge, 0 interpolated` 처럼 몇 개가 스스로 찾았고 몇 개가
보간됐는지 표시됩니다.

> 구배는 **원본 이미지 파일**에서 계산합니다. 감마 보정은 보기용이라 edge 위치 측정에
> 영향을 주지 않습니다. 이미지당 한 번만 계산해 캐시합니다.

- `H` 한 번: Pan 모드 진입
- `H` 다시 누름: 직전에 사용하던 도구로 복귀

#### 이미지 가장자리 작업

확대하면 이미지 바깥으로도 스크롤할 수 있어, **이미지의 모서리·가장자리를 캔버스 정중앙에
놓고** 작업할 수 있습니다. 여백은 빈 공간일 뿐이라 아무것도 그려지지 않으며, 마스크는
이미지 크기 그대로 유지됩니다 — 여백까지 브러시를 끌고 나가도 스트로크가 끊기지 않고
이미지 안쪽 부분만 칠해집니다. 여백은 확대했을 때만 생기므로 Fit 상태에서는
스크롤바가 나타나지 않습니다.

### 레이블 편집

Labels 패널에서 레이블 클릭 시 편집 모드 진입:

- **컨트롤포인트 드래그**: 꼭짓점을 마우스로 끌어 윤곽선 조정
- **`B` + 브러시 페인팅**: 마스크 직접 수정 (레이블을 골라도 도구는 바뀌지 않으므로 `B`를 눌러 전환)
- **Esc**: 편집 모드 종료
- **Delete 키** (Labels 목록 선택 중): 선택된 레이블 삭제
- 하단 **콤보박스**: 선택된 레이블의 클래스 변경

#### 여러 레이블 합치기 (`Home`)

`Ctrl+클릭`으로 두 개 이상 선택한 뒤 **Merge Selected Labels** 버튼 또는 `Home` 키를 누르면 하나의 레이블로 합쳐집니다. 선택은 **캔버스와 Labels 목록 양쪽에서 가능하고 서로 연동**됩니다 — 캔버스에서 Ctrl+클릭하면 목록에 반영되고, 목록에서 Ctrl+클릭하면 캔버스에 윤곽이 표시됩니다.

- 남는 레이블은 **선택된 것 중 목록에서 가장 위에 있는 것**이고, 나머지 마스크가 여기에 합쳐집니다
- 클래스가 서로 다르면 어느 클래스로 남는지 확인 창이 뜹니다
- `Ctrl+Z`로 되돌릴 수 있습니다 (원래 마스크·좌표·순서까지 복원)

> **합쳐진 레이블은 좌표가 마스크에서 다시 추출됩니다.** 병합 결과는 어떤 원본 폴리곤과도 일치하지 않기 때문입니다. 좌표를 그대로 보존해야 하는 레이블은 합치지 마세요.
>
> **떨어져 있는 영역을 합치면 저장 시 다시 나뉩니다.** LabelMe 형식은 shape 하나가 폴리곤 하나라 여러 조각을 한 shape으로 표현할 수 없습니다. 서로 닿아 있거나 겹치는 레이블을 합치면 하나로 유지됩니다.

> **좌표 보존**: 컨트롤포인트를 하나 옮겨도 **나머지 꼭짓점은 원본 좌표 그대로 저장됩니다.**
> 편집 모드의 컨트롤포인트는 마스크에서 다시 추출한 값이 아니라 해당 레이블이 들고 있는
> 원본 폴리곤이기 때문입니다. 18점짜리 폴리곤은 편집 후에도 18점으로 남습니다.
>
> **브러시로 수정해도 붓이 닿지 않은 꼭짓점은 원본 좌표 그대로 남습니다.** 스트로크가 끝나면
> 실제로 픽셀이 바뀐 구간만 마스크에서 다시 뽑고, 나머지 구간은 원래 폴리곤을 그대로 이어붙입니다.
> 18점짜리 폴리곤 가장자리를 조금 다듬으면 60점 안팎이 되고, 손대지 않은 17점은 소수점까지
> 그대로 유지됩니다. (이 기능이 없던 때는 한 번만 칠해도 540점짜리 계단 윤곽으로 통째로
> 바뀌면서 원본 정점이 전부 사라졌습니다.)
>
> 단, **스트로크가 도형 전체를 덮어버리거나 매직완드로 마스크를 새로 만들면** 보존할 원본이
> 남지 않으므로 마스크에서 추출한 고밀도 윤곽으로 대체됩니다.

### 저장 형식 (LabelMe JSON)

- 이미지당 하나의 `.json` 파일 생성
- LabelMe Format
- 어노테이션이 없는 이미지는 JSON 파일을 생성하지 않음
- shape 의 `description` 에도 `label` 과 같은 **클래스 이름**을 씁니다.
  AnyLabeling 은 레이블 목록에 이 `description` 을 보여주기 때문에, 여기에 고정 문구가
  들어가 있으면 다른 도구에서 열었을 때 클래스가 안 보입니다. 이전 버전에서 저장한
  파일은 HyLabel 로 한 번 다시 저장하면 갱신됩니다.

### Training 데이터로 내보내기

**File → Export for Training…**

라벨링 결과를 학습에 바로 쓸 수 있는 image/mask 쌍으로 내보냅니다.

```
<선택한 폴더>/
├── images/
│   ├── train/
│   │   ├── img_001.png      8bit 원본 이미지
│   │   └── ...
│   └── val/
│       └── ...
├── labels/
│   ├── train/
│   │   ├── img_001.png      배경 0, 클래스는 Classes 순서대로 1, 2, 3 ...
│   │   └── ...
│   └── val/
│       └── ...
├── classes.txt              인덱스 <-> 클래스 이름
└── split.txt                어느 파일이 train/val 중 어디로 갔는지
```

#### Train / Val 분할

기본으로 **학습 0.8 / 검증 0.2**로 나눕니다. 파일을 **셔플한 뒤** 자르므로 파일명 순서와
무관하게 섞입니다.

- 다이얼로그의 **Train / Val 분할** 그룹 체크를 끄면 예전처럼 한 폴더에 모읍니다
- **Train 비율**은 0.05 ~ 0.95에서 조절할 수 있고, 파일 수에 따라 몇 장씩 나뉘는지 바로 미리보기로 보여줍니다
- 파일이 2장 이상이면 **양쪽 모두 최소 1장**은 갖습니다 (검증 0장은 분할이 아니므로).
  1장뿐이면 train으로 갑니다
- `split.txt`에 어느 파일이 어느 쪽으로 갔는지 기록되므로 나중에 확인할 수 있습니다

> **이미지와 라벨은 절대 어긋나지 않습니다.** 분할은 파일 하나당 **한 번만, 쓰기 전에**
> 정해지고, 그 결과를 이미지와 라벨 양쪽에 그대로 씁니다. 두 번 추첨하지 않으므로 구조적으로
> 갈라질 수 없습니다. 라벨 저장이 실패하면 이미 쓴 이미지도 지워서, 마스크 없는 이미지가
> 학습에 섞이지 않게 합니다.

#### 라벨 PNG

색이 아니라 **픽셀 값 자체가 클래스 인덱스**인 8bit 흑백 PNG입니다.

| 값 | 의미 |
|---|---|
| `0` | 배경 |
| `1` | Classes 패널의 첫 번째 클래스 |
| `2` | 두 번째 클래스 |
| `n` | n번째 클래스 |

- 인덱스는 **Classes 패널의 순서**를 따릅니다. 순서를 바꾸면 인덱스도 바뀌므로, 내보낸
  데이터셋의 `classes.txt`를 기준으로 삼으세요
- 클래스가 겹치는 픽셀은 **목록에서 아래쪽 클래스가 이깁니다** (캔버스·JSON과 동일한 우선순위)
- 8bit 인덱스라 클래스는 최대 **255개**까지 가능합니다
- 라벨이 하나도 없는 이미지도 **전부 배경(0)인 라벨과 함께 내보냅니다**. 배경만 있는 이미지도
  학습 데이터이기 때문입니다

> 라벨은 저장된 JSON이 아니라 **메모리의 현재 상태**에서 만듭니다. 내보내기 전에 저장하지
> 않아도 화면에 보이는 그대로 나갑니다.

#### 8bit 변환

`.tif` 원본이 8bit가 아니면 자동으로 8bit로 변환해 PNG로 저장합니다. 16bit / int16 /
float 모두 처리합니다.

- 기본값은 **비트 깊이 전체 범위를 그대로 대응**시킵니다 (16bit면 0~65535 → 0~255).
  모든 이미지에 같은 변환이 적용되므로 프레임 간 밝기 관계가 유지됩니다
- **Auto-contrast** 체크박스를 켜면 이미지마다 자기 데이터의 0.5~99.5 백분위로 늘립니다.
  16bit 파일에 12bit 데이터가 들어 있어 결과가 어두울 때 쓰세요 (대신 이미지마다 변환이 달라집니다)

#### 크기 조절

- **Width / Height**: 1 ~ 20000 px
- **비율 고정** (기본 켜짐): 한쪽을 바꾸면 원본 비율에 맞춰 나머지가 따라갑니다
- **원본 크기** 버튼으로 되돌리기
- 이미지와 라벨은 **항상 같은 크기**로 저장됩니다. 이미지는 축소 시 area / 확대 시 linear
  보간을, **라벨은 항상 nearest** 보간을 씁니다 — 클래스 인덱스를 평균 내면 없는 클래스가
  생기기 때문입니다 (1과 3을 섞어 2를 만드는 식)
- 폴더 안에 크기가 다른 이미지가 섞여 있으면 다이얼로그가 경고합니다. 전부 지정한 크기로
  맞춰 저장되므로 일부는 비율이 달라질 수 있습니다

읽지 못한 파일이 있으면 건너뛰고 나머지를 계속 내보낸 뒤, 끝에 어떤 파일이 빠졌는지 알려줍니다.
완료 창에는 `25/25장을 내보냈습니다. (train 20 / val 5)` 처럼 분할 결과가 함께 표시됩니다.

### 감마 보정

- `G`: 감마 보정 ON/OFF
- View → Gamma Curve Setting: 커브 직접 조정

커브에는 **컨트롤 포인트 4개**가 있습니다.

| 포인트 | 움직임 | 역할 |
|---|---|---|
| 양 끝 2개 (회색) | **상하만** | 블랙 포인트 / 화이트 포인트. 좌우로 옮기면 톤 매핑이 아니라 클리핑이 되므로 X는 0·255로 고정 |
| 가운데 2개 (파란색) | **상하좌우 자유** | 곡선 모양 조절 |

가운데 점이 2개라서 **S자 곡선**(어두운 곳은 더 어둡게 + 밝은 곳은 더 밝게 = 대비 증가)이나
그 반대(대비 감소)처럼, 점 하나로는 만들 수 없던 곡선을 쓸 수 있습니다. 점 하나는 곡선을
한 방향으로만 휘게 할 수 있습니다.

- 드래그 중에는 좌측 상단에 `in → out` 값이 표시됩니다
- 가운데 두 점은 서로를 지나칠 수 없습니다 (최소 간격 `MIN_X_GAP` = 6). 스플라인은 X가 순증가해야 하기 때문입니다
- 커브는 QSettings에 저장되어 다음 실행에도 유지됩니다

> 이전 버전에서 저장해 둔 커브가 있으면 **자동으로 옮겨집니다.** 예전 형식은 X 고정(0/128/255)의
> Y값 3개만 저장해서 새 형식을 담을 수 없으므로, 기존 커브를 새 X 위치에서 다시 샘플링합니다
> (실측 편차 최대 3/255).
